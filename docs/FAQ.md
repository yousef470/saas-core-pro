# Frequently Asked Questions (FAQ)

## 1. Is this a complete SaaS application?

No.

SaaS Core is a **frontend React Admin Dashboard Template**.

It does not include a backend, database, or REST API.

---

## 2. Which technologies are used?

The template is built with:

* React
* Vite
* Tailwind CSS
* Framer Motion
* Lucide React
* Chart.js
* React Router

---

## 3. Does it include authentication?

Yes.

Included pages:

* Login
* Register
* Forgot Password
* Reset Password

The current version uses Local Storage for demonstration purposes.

---

## 4. Can I connect it to my own backend?

Yes.

The template is designed to work with any backend such as:

* Node.js
* Laravel
* Django
* ASP.NET
* Spring Boot
* Firebase
* Supabase
* REST APIs
* GraphQL APIs

---

## 5. Is the project responsive?

Yes.

It works on:

* Desktop
* Laptop
* Tablet
* Mobile Devices

---

## 6. Does it support Dark Mode?

Yes.

The template includes:

* Light Mode
* Dark Mode

Both themes are fully integrated.

---

## 7. Does it support RTL languages?

Yes.

RTL support is already implemented.

Arabic is included by default.

---

## 8. Can I use it for commercial projects?

Yes.

You can use it for personal and commercial projects according to the included license.

---

## 9. Can I customize the design?

Absolutely.

You can easily customize:

* Colors
* Typography
* Components
* Sidebar
* Navbar
* Dashboard Cards
* Charts
* Layout
* Branding

---

Yes.

Version 1.x updates will be provided free of charge.

Upcoming versions will include:

---

## 11. Does it include documentation?

Yes.

A complete documentation guide is included with the package.

---

## 12. Is this beginner friendly?

Yes.

The codebase is clean, organized, and easy to understand, making it suitable for both beginners and experienced developers.

---

## 13. Can I remove or add pages?

Yes.

The project is modular, allowing you to add, remove, or modify pages with ease.
