# Support Policy

Thank you for purchasing **SaaS Core Admin Dashboard**.

This document explains what is included in the support service.

---

# Included Support

We are happy to help with:

* Installation issues
* Project setup
* Build errors
* Missing files
* Template bugs
* Questions about existing components
* Documentation clarification

---

# Not Included

Support does **not** include:

* Backend development
* Database creation
* Authentication server setup
* API development
* Third-party integrations
* Custom feature requests
* Custom dashboard design
* Business logic implementation
* Deployment services

---

# Bug Reports

If you discover a bug inside the template:

Please include:

* A clear description
* Steps to reproduce the issue
* Screenshots (if available)
* Browser information
* Operating System
* Error messages (if any)

Verified bugs will be fixed in future updates whenever possible.

---

# Response Time

Typical response time:

**24–48 hours**

Business days only.

Response times may be longer during holidays.

---

# Future Updates

Version **1.x** updates are included free of charge.

Future updates may include:

* New dashboard pages
* UI improvements
* Performance optimizations
* Bug fixes
* Additional reusable components

---

# Custom Work

If you need:

* Backend development
* API integration
* New pages
* Additional features
* Full SaaS development

These services are **not included** with this purchase and may require a separate agreement.

---

# Contact

For support inquiries, please contact through the marketplace where you purchased the template.

When contacting support, include:

* Purchase information
* Template version
* Description of the issue

---

Thank you for supporting **SaaS Core Admin Dashboard**.

We appreciate your feedback and will continue improving the template with future updates.
