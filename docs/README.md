# Overview

SaaS Core is a complete Admin Dashboard Template created using React and Vite.

Instead of building an admin panel from scratch, SaaS Core provides a complete foundation including dashboards, CRM, products, billing, analytics, users, authentication, notifications, chat, settings, and much more.

The project is fully responsive and supports both Light & Dark themes.
