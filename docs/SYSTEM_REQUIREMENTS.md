# System Requirements

Before running **SaaS Core Admin Dashboard**, make sure your environment meets the following requirements.

---

# Minimum Requirements

## Node.js

Version:

18.x or higher

Recommended:

20.x or later

Download:

https://nodejs.org/

---

## Package Manager

One of the following:

* npm
* pnpm
* yarn

The template is configured using **npm** by default.

---

## Operating Systems

Supported:

* Windows 10 / 11
* macOS
* Linux

---

## Browsers

Latest versions of:

* Google Chrome
* Microsoft Edge
* Mozilla Firefox
* Safari

---

## Recommended Code Editor

Visual Studio Code

Recommended Extensions:

* ESLint
* Prettier
* Tailwind CSS IntelliSense
* Auto Rename Tag
* Path IntelliSense

---

# Installation

Install project dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Create production build

```bash
npm run build
```

Preview production build

```bash
npm run preview
```

---

# Build Output

Production files are generated inside:

```text
dist/
```

---

# Internet Connection

Internet is required only for:

* Installing packages
* Downloading dependencies

The dashboard itself runs completely offline after installation.

---

# Backend

This version does **not** require a backend.

All demo data is stored using **Local Storage**.

You can replace it with:

* REST API
* GraphQL
* Firebase
* Supabase
* Node.js Backend
* Laravel
* Django
* ASP.NET
* Spring Boot

---

# Performance

Recommended:

* 8 GB RAM or more
* Modern multi-core processor

The template is optimized for fast loading and smooth interactions.

---

# Compatibility

The template is compatible with:

* React
* Vite
* Tailwind CSS

It can be integrated into existing React applications with minimal changes.
