# SaaS Core Admin Dashboard

## Documentation

Version 1.0.0

---

# Introduction

Thank you for purchasing SaaS Core Admin Dashboard.

SaaS Core is a modern React Admin Dashboard template designed for SaaS products, startups, agencies, and internal management systems.

The project is built with clean architecture and reusable components to help developers build dashboards much faster.

---

# Technology Stack

* React 19
* Vite
* Tailwind CSS
* Framer Motion
* Lucide React
* Chart.js
* React Router
* Local Storage

---

# Installation

Install dependencies

```
npm install
```

Start development server

```
npm run dev
```

Create production build

```
npm run build
```

Preview production build

```
npm run preview
```

# Data Storage

Current version stores data locally using

```

```

No backend is required.

You can easily replace Local Storage with your own REST API or database.

Service files are located inside

